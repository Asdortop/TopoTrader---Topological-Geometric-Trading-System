⚠ Causality Guarantee
Chomp1d
Conv1d pads both sides. Chomp1d removes right-side padding after every conv. Output at time t uses only t, t−1, t−2 ... → zero look-ahead bias.
return x[:, :, :-chomp_size]
🧮 Activation
SELU (not ReLU)
Self-normalizing — keeps activations near μ=0, σ=1 without BatchNorm. BatchNorm would corrupt temporal structure.
📏 Weight Norm
weight_norm(Conv1d)
Decouples magnitude and direction of weights. Faster convergence, more stable gradients vs batch statistics.
🔭 Memory Horizon
2000+ Trading Days
Receptive field grows exponentially with dilation. vs LSTM practical limit of ~200 steps.
LSTM fails at T≈200
TCN: 100% at T=1000+
⚡ Training
Fully Parallel
No sequential BPTT like RNNs. All timesteps processed in parallel. Fixed gradient path by depth — no vanishing gradients.
BCELoss + Adam(lr=1e-3)
Epochs: 20 · Batch: 32
